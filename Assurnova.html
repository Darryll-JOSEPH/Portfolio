Vue d'ensemble Project Overview

La Direction Data Marketing de la compagnie d’assurance AssurNova souhaitait une vision claire et dynamique du portefeuille clients sur différentes périodes. J’ai conçu dans Power BI des rapports interactifs permettant de suivre l’évolution des clients (nouveaux / churnés), de profiler le portefeuille et d’estimer les clients ciblables pour des campagnes marketing selon des filtres dynamiques. AssurNova’s Data Marketing team needed a clear, dynamic view of customer base across periods. I built interactive Power BI reports to track customer evolution (new / churned), profile the portfolio, and estimate targetable customers via dynamic filters.

  • Sources : Excel (hébergés sur SharePoint pour mise à jour automatique) & SQL Server (Power BI Desktop) Sources: Excel (hosted on SharePoint for dynamic refresh) & SQL Server (Power BI Desktop)
  • Préparation : Power Query (nettoyage, transformation) & DAX (modèle, mesures) Preparation: Power Query (cleaning, transform) & DAX (model, measures)
  • Rapports : KPIs, barres, secteurs, cartes & filtres interactifs Reports: KPIs, bars, pies, cards & interactive slicers
  • Gouvernance : RLS (Row-Level Security), espaces de travail dédiés, rafraîchissement planifié Governance: RLS, dedicated workspaces, scheduled refresh
  • Collaboration : Versionning Git & Power BI Service (partage/sécurité) Collaboration: Git versioning & Power BI Service (sharing/security)
